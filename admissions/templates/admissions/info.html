FAQs

Frequently Asked Questions

Is there an entrance examination?
Primary and Secondary applicants may be required to sit for a brief placement assessment to determine an appropriate class level.
Can I apply for more than one child at once?
Yes. Please submit a separate application for each child so that each receives its own reference number.
How will I know my application status?
Use the "Track Application" page with your reference number at any time to view your live application status.
Is the application fee refundable?
No, the application processing fee is non-refundable regardless of the outcome.
What documents do I need to upload?
A passport photograph, birth certificate and, where applicable, the applicant's most recent school result.
